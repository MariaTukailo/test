# Выбор интеграции с Календарем (iCal) для MVP

## Контекст и постановка задачи
Во втором раунде переговоров Заказчик попросил добавить функцию добавления мероприятия в личный календарь пользователя. Какую технологию использовать для реализации этой функции?

## Драйверы решения
1. **Простота реализации:** Необходимо решение, которое можно реализовать за 1.5 недели без сложной авторизации.
2. **Универсальность:** Решение должно работать на устройствах с разными ОС.
3. **Сроки:** Функция должна быть реализована в рамках текущего дедлайна.

## Рассмотренные варианты
* Прямая интеграция с Google Calendar API (требует OAuth).
* Генерация стандартного файла `.ics` (iCalendar).

## Итог решения
Выбран вариант **«Генерация `.ics` файла»**. Это стандартный формат, который поддерживается всеми популярными календарями (Google Calendar, Apple Calendar, Outlook).

### Последствия
* **Хорошо:** Реализация проста и надежна, не требует сложной OAuth-авторизации.
* **Хорошо:** Работает на любых устройствах.
* **Плохо:** Пользователю нужно вручную открыть файл и подтвердить добавление.

### Подтверждение
Проверка наличия зависимости для генерации `.ics` (например, библиотека `ical4j`) в `pom.xml`.

## Плюсы и минусы вариантов
### Google Calendar API (прямая интеграция)
* **Хорошо:** Автоматическое добавление без участия пользователя.
* **Плохо:** Требует настройки OAuth 2.0, что усложняет разработку.

### Генерация `.ics` файла
* **Хорошо:** Универсально для всех календарей.
* **Хорошо:** Просто в реализации (нет сложной авторизации).
* **Плохо:** Требует одного лишнего клика от пользователя.
