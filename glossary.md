# Глоссарий проекта «Evently»

| Термин | Определение |
| :--- | :--- |
| **API** | Application Programming Interface: программный интерфейс для интеграции приложения с внешними сервисами (например, Яндекс.Карты или Google Calendar). |
| **ADR** | Architectural Decision Records: документ, фиксирующий архитектурные решения и обоснование выбора технологий (базы данных, фреймворков). |
| **MVP** | Minimum Viable Product: минимально жизнеспособный продукт, первая версия с базовым функционалом, достаточным для запуска. |
| **SDD** | Software Design Description: документ, описывающий архитектуру, структуру слоев и дизайн программного обеспечения. |
| **SRS** | Software Requirements Specification: спецификация требований к программному обеспечению. |
| **UI** | User Interface: пользовательский интерфейс, визуальная часть приложения, с которой взаимодействует пользователь. |
| **Виш-лист** | Список желаемых подарков, формируемый участниками мероприятия. |
| **Итерация** | Короткий цикл разработки (спринт), в конце которого создается работающая версия продукта (инкремент). |
| **Комната** | Виртуальное пространство мероприятия, где хранится информация о событии и происходит взаимодействие пользователей. |
| **Организатор** | Пользователь, создавший мероприятие. Обладает полными правами на управление настройками, бюджетом и командой. |
| **Участник команды** | Пользователь, приглашенный Организатором для помощи в подготовке события. Имеет расширенные права на редактирование контента. |
| **Участник (Гость)** | Приглашенный пользователь с базовым доступом к «комнате» мероприятия (просмотр, подтверждение участия, добавление пожеланий). |
| **Чек-лист** | Список задач по подготовке к мероприятию с возможностью назначения ответственных и отметки выполнения. |
